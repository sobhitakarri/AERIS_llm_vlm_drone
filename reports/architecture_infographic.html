AERIS — Adaptive Embodied Reasoning Indoor System

Natural-language indoor drone stack: the LLM/VLM may only emit Skill DSL JSON. Fast vision is OpenCV (CSRT). The VLM identifies an object once and recovers a lost track. Stale coordinates cannot generate a new movement command.

Phase-1 architecture · landscape poster Indoor workspace X/Y ±1.5 m · Z 0.2–1.5 m
LiteWing hover clamp 0.20–0.80 m · UDP 192.168.43.42
Backends: sim · MATLAB twin · PySimverse · real LiteWing

frontend/index.html · app.js · telemetry.js

  • Natural-language command box and abort / home.

  • MJPEG overlay of live boxes from StateManager.
  • Backend switch: sim / matlab / pysimverse / litewing — rewires executor and perception loop.

2 · API + process wiring

backend/api/server.py · routes.py

  • POST /api/command — one mission at a time (executor.is_busy()).
  • Parse intent → if vision then UAVVLAPipeline, else LLM/code-first.
  • set_targets() points the 10 Hz loop at this mission’s objects.
  • On EVENT_MISSION_FINISHED: clear targets, reset trackers, clear objects.
  • On EVENT_TARGET_LOST: drop pending replan; strip world coordinates.

3 · Shared runtime fabric

  • EventBus — OBJECT_DETECTED, TARGET_LOST, step / abort / finish.
  • StateManager — drone pose + objects; only actionable objects may move the drone.
  • UavMonitor — NeLV UAV Monitor: arm, step, abort, snapshot.
  • MissionPlanner FSM: IDLE → PLANNING → EXECUTING → REPLANNING → DONE / ERROR.

4 · Understand the command (Obj 1)

intent_router.py · local_planner.py · plan_cache.py

Code-first

Dictionary / regex: takeoff, land, hover, return, goto, relative, rotate, circle, named shapes. Compound phrases (then, trace, letter) skip the dictionary.

Disk cache

cache/mission_plans.json — exact + numeric-template hits. LLM only if both miss.

LLM planners

Gemini Interactions API, or local Qwen2.5-3B (planning) + Qwen2-VL-2B (boxes).

7 · Safety (Obj 6)

safety_validator.py · skill_dsl.py

Allowed skills only: TAKEOFF, LAND, HOVER, MOVE_TO, ROTATE, CIRCLE, FIND, INSPECT, RETURN. No PWM, no velocity from the VLM.

Geofence X/Y ±1.5 m, Z 0.2–1.5 m. CIRCLE radius checked. Every replan is validated again before inject.

8 · Perception-action loop (Obj 3–5, 9) — VLM once, OpenCV always

CameraManager~15 Hz grab thread. Latest frame only. Join before release.
VLM identifyQwen2-VL / Gemini. Absolute pixels or 0–1000 yxyx. Plausibility gate rejects whole-image boxes.
CSRT tracker~46 FPS @ 640×480. Class/colour agnostic. KCF fallback. MIL rejected (never reports loss).
Health checksScale ×3, aspect ×2.5, jump 35% diagonal, NCC debounce 5 frames.
Homography HPixel centre → (X,Y) m. Load/save cache/homography.json.
StateManagerLive objects. actionable=false strips world_x/y.
LockTRACKING → anomaly keep · confirmed fail SEEKING · VLM miss TARGET_LOST · hold, no MOVE_TO

9 · Mission executor

mission_executor.py

  • Sequential Skill dispatch. Unknown skill = fail.
  • FIND / INSPECT: live VLM or actionable state only.
  • TARGET_LOST → hover in place (never last-known pose).
  • inject_replan inserts after the current step and keeps the tail (LAND is never dropped).
  • Replan queued during LAND is discarded.
  • Step failure: controlled land, then e-stop.

10 · Replan (Obj 10) — AutoFly loop, UAV-VLA actions

replan_manager.py · _on_replan in server.py

  • Anchor = pose the plan was built around (not previous frame).
  • Drift ≥ 0.3 m for 3 consecutive detections, 2 s cooldown, max 3 / mission.
  • Ignored if drone on ground, disarmed, or target not actionable.
  • Emits MOVE_TO + HOVER through SafetyValidator, then inject.

Taken from AutoFly: continuous observation while flying. Refused: RGB→velocity VLA, PWM from the model.

Skill DSL — the only language the models may speak

TAKEOFF z LAND HOVER t MOVE_TO x y z ROTATE angle CIRCLE radius FIND target INSPECT target RETURN

Same JSON for sim, MATLAB twin, PySimverse, and the physical LiteWing. Python never writes motor PWM.

11a · SimInterface

In-process mock. Instant takeoff / goto / land. Used by the 150-test suite and the dashboard default.

11b · MATLAB digital twin

Newton–Euler 6-DOF + cascaded PID. Python UDP 5005 commands / 5006 telemetry. Simulink + Aerospace Blockset for 3D. UDP chosen over TCP: no retransmission stall on a 50 Hz loop.

11c · PySimverse

Unity camera + RC. get_frame() for VLA when stream source is simverse.

11d · LiteWing (real)

cflib CRTP udp://192.168.43.42. Firmware: Circuit-Digest ESP-Drone. Optical-flow dead reckoning (scale 3.7). Hover setpoints only. Battery < 3.40 V refuses flight. High-level commander unlock on connect.

Rates

Control 50 Hz · flow 100 Hz · camera ~15 Hz · perception 10 Hz · VLM re-confirm 8 s · miss backoff 3→60 s

Tracker bench

CSRT 45.9±9 FPS, IoU 0.96; reports loss; no re-acquire. KCF 197 FPS IoU 0.80. MIL never reports loss (rejected). See Research_Benchmarks.xlsx.

VLM box hygiene

Shared bbox_convert.py. Gemini 0–1000 yxyx asserted. Qwen asked for absolute pixels. No prose-integer parse. Offline Gemini returns not-found, never a fake centre box.

What we refused

Outdoor lat/lon. End-to-end velocity VLA. VLM every frame. LLM PWM. Two concurrent missions. Flying after LAND via late replan.

Tests

150 unit tests: intent, VLA, NeLV, CSRT lock, TARGET_LOST hold, replan insert-not-truncate, static name resolution (catches missing MAX_HOVER_Z).

Hard rules (architecture contract)
  • Models emit Skill JSON only. Fast loop never calls Gemini/Qwen every frame.
  • Grounding is metres in the room, never lat/lon.
  • Replan must pass SafetyValidator. Concurrent commands are rejected.
  • TARGET_LOST: stale visual information cannot independently generate a movement command.
